# CITADEL SIEGE 8.1 — ORIGINAL WORLD

Experimental preview: https://pas9136.github.io/citadel-siege/preview-8-1/

Uses the supplied W3X's actual static pathing, terrain and spatial records.
See [accuracy and acceptance report](ACCURACY.md), [interactive comparison](compare.html),
[comparison image](comparison.png), and [test results](test-results.json).

Dynamic object footprints and complete gate behavior are not yet reconstructed;
this is not a claim of full specification completion. Earlier releases and saves
are preserved. Select Map for the expanded mobile minimap and use the zoom slider.
